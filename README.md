\# Commerce Intelligence Platform



A commerce analytics and AI business intelligence platform for Shopify merchants.



\## Technology Stack



\### Backend

\- ASP.NET Core

\- Entity Framework Core

\- PostgreSQL



\### Frontend

\- Angular

\- TypeScript

\- SCSS



\### Infrastructure

\- Docker

\- Docker Compose

\- GitHub Actions



\## Repository Structure



\- `backend/` — ASP.NET Core backend and tests

\- `frontend/` — Angular application

\- `infrastructure/` — Docker and deployment configuration

\- `docs/` — Architecture and development documentation

\- `scripts/` — Developer automation

\- `.github/` — GitHub Actions and repository configuration
