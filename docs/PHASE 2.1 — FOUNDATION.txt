[SOLUTION CREATION]

Goal
- Create the backend solution foundation before adding projects.

Files
- CommerceIntelligencePlatform.sln
- global.json
- Directory.Build.props
- Directory.Packages.props

global.json
- Pins the .NET SDK version for all developers.

Directory.Build.props
- Shared build settings.
- TargetFramework = net10.0
- Nullable enabled.
- ImplicitUsings enabled.
- Central compiler configuration.

Directory.Packages.props
- Centralized NuGet package management.
- All package versions managed in one file.

Verification
- dotnet sln list
- dotnet build

Commit
- chore: create solution foundation
